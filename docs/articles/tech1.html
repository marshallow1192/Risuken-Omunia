JetNet を使ってみた 1

公開日 : 2026年2月3日

はじめに

物理学科に来てしまった故ひさしくpython と ai 関係のことをしていなかったのでリハビリを込めてGNNを用いて分類タスクを行ってみました．

普通のやっても面白くない(訳:物理関係のことをやりたい)ので今回はJetNet という素粒子のジェットについてのデータセットを用いました．

このJetNet かなり物理学科の人間としてはおもしろいものなのですが，qiita にも記事がなかったのでこのデータセットの使い方と今回行ったことの記録を書いておきます．

物理学科の人間にとってのMNISTになる未来が見えるかも....？

今回はデータセットの読み込み方法とデータの内容について解説します．

JetNet を導入する

お手元の仮想環境なりColab なりを開いていつも通り

pip install jetnet

とすればインストールできます．仮想環境ならこれでよいのですがなぜかColabでやろうとすると一度セッションを切られてしまいます(おそらくColabにはいってるnumpyとかのライブラリの古いバージョンを無理やりダウンロードしようとしてるから??)

ですがセッションを再起動したら問題なく動きます

データセットを導入

データセットを導入しましょう．

from jetnet.datasets import JetNet

particle_data, jet_data = JetNet.getData(

    jet_type=["g","q","t","w","z"], data_dir="./datasets/jetnet/", download=True

)

この関数の引数の jet_type はどの種類のジェットを読み込むかを示しており，

記号 ジェットの種類
g グルーオン
q クォーク
t τ粒子
w Wボソン
z Zボソン

となっており，必要な分だけ取り出すことができます．

(例えばグルーオンとクォークのデータだけほしかったら jet_type=["g","q"] とすればよろし)

このデータセットを読み込む際にデータがダウンロードされますが，その保存場所は data_dir により定められます．

もしColabでこのデータセットを読み込む際，ご自身の Drive に接続してそこにダウンロードしないとセッションを立ち上げるたびにリセットされていちいちダウンロードすることになるのでマウントしてからダウンロードしましょう．

返り値の１つ目に1つのジェットに含まれるそれぞれの粒子のデータが二次元配列として入り，２つ目に１つのジェット全体としてのデータが入ります．

粒子のデータはこのようになっており

例

particle_data[0][0] 

[0.06290796, 0.05512052, 0.36435664, 1]

#["etarel", "phirel", "ptrel", "mask"]

0番目と1番目のデータがそれぞれ $ \eta_{rel} $ $ \phi_{rel} $ というジェットの中心軸からその粒子が$ \eta $ $ \phi $ 方向にどれだけ離れているかを表す相対的な量となっています．

$ \eta_{rel} = \eta_{particle} - \eta_{jet} $

$ \phi_{rel} = \phi_{particle} - \phi_{jet} $

これのおかげでデータの回転対称性が担保されています．

2番目のデータが運動量を示し，ジェット全体の運動量とその粒子一つが持つ運動量の比として保存されています．

3番目のデータはそのデータがゼロ埋めとして追加されたものかどうかを示しており，1だったら有効なデータであり，0ならそれがゼロ埋めとして追加されたものであることを示しています．

なので分析の際はここが1のデータのみ使いましょう．

またジェットのデータはこのようになっており，

例
jet_data[0]

[4, 1.05790161e+03, 4.72092062e-01, 8.89337082e+01,30]
#["type", "pt", "eta", "mass", "num_particles"]

0番目のデータがそのジェットの種類を表し，データセットを読み込むときに指定した jet_type の配列の要素の位置として表されています．

(上の例なら["g","q","t","w","z"] の４番目なのでZボソンのデータ)

1から3番目のデータはそれぞれジェットの運動量，検出器の中心からの角度，ジェットの質量 を表しています．

そして4番目のデータは１つのジェットに含まれる粒子の数を示しています．これは１つのジェットに対する粒子のデータでmask = 1 つまり有効なデータの数を示しています．

データとJetNetの解説はこんな感じです．

getData 関数はほかに粒子データ，ジェットデータを正規化するかなどを指定する引数があるのですが今回は使わないので省きました．詳しく見たい方はこちらの公式サイトをご参照ください．
